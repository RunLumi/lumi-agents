# Development icon

`lumi-development.svg` is an original geometric L made for this repository under
its Apache-2.0 license. The PNG and ICO encode the same two rectangles/polygon
on a 64 by 64 canvas for Tauri's compile-time icon requirements.

This neutral development asset makes a clean build reproducible. It is not a
claim of approved customer-release branding. No external image was copied or
modified; pre-existing ignored local icons remain untouched.
